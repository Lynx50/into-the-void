Upgrade the bubble system in my app "Into the Void" to make bubbles feel like realistic glass spheres with improved motion and depth.

MAIN GOAL:
Make bubbles feel physical, alive, and premium — not like UI elements.

==================================================
1. IMPROVE GLASS REALISM (CRITICAL)
==================================================

Enhance each bubble with more convincing glass-like properties:

A. STRONGER EDGE RIM
- Add a slightly brighter, sharper rim around the bubble edge
- The rim should be subtle but clearly define the sphere
- Use a soft gradient, not a hard outline

B. SPECULAR HIGHLIGHT (REFLECTION)
- Add a more visible highlight spot near the top-left of each bubble
- Shape: soft oval or circular glow
- Opacity: low but noticeable
- This should simulate reflected light

C. SECONDARY LIGHT REFLECTION
- Add a very faint secondary highlight on the opposite side
- This creates more realism and curvature

D. INNER SHADING
- Slightly darken the center of the bubble
- Keep edges slightly brighter
- Use radial gradient

E. SUBTLE BACKGROUND DISTORTION (IMPORTANT)
- Simulate a glass effect by slightly distorting or blurring the background behind the bubble
- Keep it very subtle
- If full distortion is not possible, fake it with layered gradients and transparency

F. COLOR TINT
- Use a very light blue/purple tint
- Keep opacity low
- Avoid opaque or milky look

==================================================
2. ADD DEPTH THROUGH LAYERED BUBBLES
==================================================

Create 3 depth layers:

Layer 1 (far background):
- very small bubbles
- very low opacity
- slow movement

Layer 2 (mid layer):
- medium size bubbles
- moderate opacity
- moderate speed

Layer 3 (foreground):
- larger bubbles
- slightly more glow
- slow but noticeable drift

Ensure:
- bubbles overlap naturally
- some pass behind UI elements
- some feel closer to the user

==================================================
3. IMPROVE MOTION SYSTEM (VERY IMPORTANT)
==================================================

Replace uniform movement with organic motion:

For each bubble:
- assign a random speed
- assign a random direction
- assign a slight vertical or horizontal drift

Add:

A. FLOATING MOTION
- gentle up/down oscillation (like floating in water)

B. DRIFT
- slow sideways movement

C. SPEED VARIATION
- some bubbles very slow
- some slightly faster
- no identical movement patterns

D. LOOPING
- when bubbles exit screen, respawn smoothly from another edge

E. EASING
- use smooth easing (no linear robotic motion)

==================================================
4. ADD SIZE VARIATION
==================================================

Randomize bubble sizes:
- small (background)
- medium
- large (foreground)

Keep proportions realistic:
- avoid extreme sizes
- maintain soft visual balance

==================================================
5. IMPROVE HOME SCREEN ATMOSPHERE
==================================================

- Ensure background bubbles are visible but subtle
- Add 1–2 larger slow-moving bubbles behind the UI card
- Keep everything calm and not distracting

==================================================
6. OPTIONAL MICRO-INTERACTIONS (IF POSSIBLE)
==================================================

- Slight scale pulse on hover or tap
- Very soft glow increase on interaction
- No aggressive animations

==================================================
7. KEEP THE STYLE CONSISTENT
==================================================

Do NOT:
- make bubbles too bright
- add heavy glow
- make them cartoon-like
- overuse blur

DO:
- keep everything soft
- minimal
- premium
- calming

==================================================
FINAL RESULT
==================================================

The bubbles should feel like:
"soft glass spheres drifting slowly through a quiet night sky"

NOT like:
- flat UI circles
- glowing blobs
- background decoration

They should feel:
- physical
- layered
- alive
